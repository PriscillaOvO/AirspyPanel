# AirspyPanel 2.0 使用说明

## 安装与首次运行

从 https://github.com/PriscillaOvO/AirspyPanel/releases 下载 GUI ZIP，完整解压到可写目录。保留 `AirspyPanel.exe.config` 与可执行文件在同一文件夹。

面板需要 .NET Framework 4.8 或更新的 4.x 运行环境。

另行下载并解压 ADS-B SPY Windows 版：https://airspy.com/download/ 。保留解码器原包内的 DLL。地图功能需要另行安装 VRS：https://www.virtualradarserver.co.uk/Download.aspx 。

打开面板，在左侧选择 `airspy_adsb.exe` 和（可选）`VirtualRadar.exe`，点击保存。面板会查找常见 Program Files 目录内的 VRS；未找到时通过浏览按钮选择实际位置。

## 接收

接好 Airspy R0 / R2 / Mini 与 1090 MHz 天线，关闭占用同一接收机的软件。默认端口为 30005，增益 auto、过滤强度 4，采样模式自动；点击“开始接收”。

“Beast 已连接”仅说明 TCP 连接正常；“正在收到报文”表示已收到数据。没有飞机时先检查设备、天线、USB 和接收环境。

双信号条显示最近 3 秒 Beast 报文的相对平均与峰值电平，不代表 dBm 或天线噪声底。飞机数统计最近 60 秒 DF11 / DF17 显式 ICAO 地址，未收到新消息的飞机会超时移出。

## VRS 地图联动

1. 确认 VRS 程序路径。地图地址默认 `http://127.0.0.1/VirtualRadar/`；如果 VRS 使用其他网页端口，按其主界面链接填写。
2. 点击“一键联动 VRS”。这会配置 `Airspy Panel` 接收机并设为网页默认接收机。VRS 正在运行时，面板会询问是否正常关闭并重启。
3. 配置使用 TCP、127.0.0.1、与面板一致的数据端口、Beast 格式。即使自定义端口为 30003，数据格式仍应选 Beast。
4. 网页连接与接收机来源检查通过后，点击“打开飞机地图”。

VRS 的跟踪规则与面板不同，飞机数不必完全相同。地图底图需要可用的互联网服务，底图加载失败不等于本机接收失败。旧版 VRS 提示安装 .NET Framework 3.5 时，需要单独完成该 Windows 功能安装。

## 参数与退出

12 / 20 / 24 MHz 是采样模式，不是接收频率；24 MHz 仅选择用于支持该模式的 R2。位打包对应 `-p`；面板默认不启用 Bias-Tee 供电。

运行中修改接收参数前先停止接收。面板只停止自己启动的解码器；关闭面板会询问是否停止接收，VRS 保持独立运行。

## 设置与备份

- `AirspyPanel.settings.xml` 保存在面板旁边，包含个人路径和接收参数。升级时可保留，但不要上传到公开仓库。
- VRS 配置位于 `%LOCALAPPDATA%\VirtualRadar\Configuration.xml`。联动修改前会在同目录生成带 `.panel-backup-时间戳` 的备份。
- 恢复 VRS 配置前正常退出 VRS，将所需备份复制回 `Configuration.xml`，再重新启动。
- 接收日志仅在界面保留近期内容，需要保存时点击“导出日志”。

## 排查

- 找不到程序：重新选择正确的 EXE，完整解压第三方下载包。
- 端口占用：停止占用进程或更换数据端口，之后重新联动 VRS。
- 解码器退出：查看日志，检查设备驱动、USB、采样模式和是否被其他 SDR 软件占用。
- VRS 网页未连接：确认 VRS 正在运行，并核对地图网址和网页端口。
- VRS 来源不符：重新联动，检查名为 `Airspy Panel` 的接收机。
- 无法保存设置：将完整面板文件夹放在当前用户可写位置。
