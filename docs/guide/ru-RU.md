## Установка и обновление

AirspyPanel — независимая панель Windows для приёма ADS-B через Airspy и управления Virtual Radar Server (VRS). Это не официальный продукт Airspy или VRS. Требуются Windows 10/11 и .NET Framework 4.8. Среда разработки проверялась на Windows 11 x64; автоматические тесты не подтверждают совместимость со всеми системами и реальным радиооборудованием.

Скачайте установщик EXE или переносимый ZIP из [Releases](https://github.com/PriscillaOvO/AirspyPanel/releases). Сверьте SHA-256 командой PowerShell `Get-FileHash` с `SHA256SUMS.txt`. Пакеты не подписаны; не отключайте защитное ПО. Установка выполняется для текущего пользователя, ярлык рабочего стола необязателен, автозапуск не добавляется. Перед обновлением выйдите из панели. Настройки сохраняются при обновлении и по умолчанию при удалении; их удаление требует явного выбора. Тихое удаление сохраняет настройки.

Полностью распакуйте ZIP и запустите `AirspyPanel.exe`, оставив рядом `.config`. Обе версии хранят настройки в `%LOCALAPPDATA%\AirspyPanel`. Старые порты, усиление и пути сохраняются. Старые китайские настройки остаются китайскими; новые следуют языку системы, при отсутствии поддержки выбирается английский.

## Первый запуск

Отдельно установите [ADS-B SPY для Windows](https://airspy.com/download/) и [VRS](https://www.virtualradarserver.co.uk/Download.aspx). Сохраните DLL из пакета декодера. Сторонние программы и драйверы не включены. VRS может дополнительно требовать компонент Windows .NET Framework 3.5.

В настройках найдите программы автоматически либо выберите `airspy_adsb.exe` и `VirtualRadar.exe` в разделе программ и карты. Поиск проверяет обычные папки, допускает отмену, пропускает недоступные каталоги и ссылки на каталоги. Он не обходит все диски, не запускает программы и не меняет VRS. При необходимости укажите конкретную папку. Рабочие пути сохраняются; при нескольких результатах нужен выбор. Сохраните результат явно.

Подключите Airspy R0/R2/Mini и антенну 1090 МГц, закройте другие программы, использующие устройство. Начните приём, настройте и запустите VRS, затем откройте карту. Работающий локальный VRS штатно закрывается; настройки резервируются и обновляются, затем VRS запускается без повторного подтверждения. Ошибка закрытия отображается; принудительного завершения нет.

## Карта, состояние и уровни

Стандартный URL: `http://127.0.0.1/VirtualRadar/`. Адрес `/VirtualRadar/desktop.html#` также допустим; панель формирует `AircraftList.json`. Если веб-порт изменён, укажите его в URL. Декодер и VRS должны использовать один TCP-порт данных (по умолчанию 30005) и формат Beast. Веб-порт — отдельная настройка.

Серый: не проверено; зелёный: API, источник и настройки совпадают; жёлтый: API работает, но источник или настройки требуют проверки; красный: недоступно. Нажмите на состояние для времени проверки и подробностей. Ноль самолётов допустим. Ошибка подложки карты не означает ошибку локального API. При нескольких приёмниках выберите источник в настройках; пользовательские имена допустимы. Несовпадение локальных настроек не блокирует открытие карты.

Средний и пиковый уровни вычисляются по сообщениям Beast за три секунды: 0–255 преобразуются в 0–100 %. Это не калиброванные dBm, спектр или уровень шума. Самолёты считаются по уникальным явным ICAO из DF11/17 за 60 секунд. VRS может использовать другие правила.

## Управление и предпочтения

Полное окно можно менять в размере; компактное фиксировано около 320×620 DIP с ограничением рабочей областью экрана. Настройки, журнал и детали открываются внутри него. Переключение режима не перезапускает приём. Доступны светлая, тёмная, системная темы и шесть языков. Язык меняется сразу, без сброса приёма и ввода; исходный вывод сторонних программ и системные ошибки остаются без перевода.

Остановить всё завершает декодер панели и штатно закрывает локальный VRS, включая запущенный вручную. Вкладки карты остаются открытыми. Выход использует тот же порядок. Если VRS не закрывается, повторите, отмените или явно выйдите только из панели. В трее приём продолжается. Первый выбор закрытия можно запомнить и изменить в настройках оформления. Двойной щелчок по значку возвращает прежнюю страницу; повторный запуск показывает уже работающий экземпляр.

Журнал доступен в настройках. По умолчанию показаны важные события; предупреждения и ошибки выделены, повторы объединены. Исходный вывод — отдельно. Прокрутка вверх приостанавливает слежение; «К новым» возобновляет. Экспорт учитывает текущий вид и фильтр. Каждый вид хранит до 500 записей в памяти; обычный журнал приёма автоматически на диск не сохраняется.

Дополнительные параметры: усиление auto или 0–21, избыток вызывает искажения. 12/20/24 МГц — дискретизация, не частота приёма 1090 МГц и не самостоятельный MLAT; 24 МГц требует совместимый R2. Фильтр 1–60, по умолчанию 4; большее значение может нагружать CPU. Упаковка USB `-p` относится к передаче, не к питанию Bias-Tee. Рекомендуемые значения не меняют пути и URL карты.

## Диагностика, разработка и лицензия

Без сообщений проверьте занятость устройства, антенну, USB, драйвер и условия приёма. Для VRS проверьте URL, веб-порт и службу. Подробности различают тайм-аут, неверный HTML/JSON и другой источник. Если получена страница AdGuard, проверьте локальные правила фильтрации. Ноль самолётов сам по себе не свидетельствует о неисправности.

Резервные копии VRS находятся рядом с настройками в `%LOCALAPPDATA%\VirtualRadar`. Перед ручным восстановлением закройте VRS. В отчёте об ошибке укажите версию, Windows, язык и шаги; удалите личные пути, местоположение, принятые данные и секреты перед отправкой. Фактический объём проверок указан в отчёте репозитория.

Сборка: `powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1`, результат в `bin`. Проверки: `bin\AirspyPanel.exe --self-test`, `--render`, `--render-languages`. Требования установщика описаны в CONTRIBUTING.md.

Поток данных: Airspy → ADS-B SPY → Beast TCP → панель и VRS → карта браузера. Панель управляет и наблюдает, не заменяя декодер или сервер карты. Собственный код и документация — MIT; сторонние продукты сохраняют свои лицензии. Право распространения ADS-B SPY не предполагается.
