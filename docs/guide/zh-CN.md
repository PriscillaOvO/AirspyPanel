# AirspyPanel 3.0 使用说明

[English](en-US.md) · [简体中文](zh-CN.md) · [日本語](ja-JP.md) · [Français](fr-FR.md) · [Deutsch](de-DE.md) · [Русский](ru-RU.md)

## 安装与升级

AirspyPanel 是独立社区开发的 Airspy ADS-B 接收与 VRS 控制面板，不是 Airspy 或 VRS 官方产品。需要 Windows 10/11 和 .NET Framework 4.8；开发验证平台为 Windows 11 x64，自动测试不等于对其他系统或真实接收硬件的认证。

在 [Releases](https://github.com/PriscillaOvO/AirspyPanel/releases) 下载安装 EXE 或免安装 ZIP，使用 PowerShell `Get-FileHash` 与 `SHA256SUMS.txt` 核对。当前包未数字签名，不要关闭安全软件。安装版只为当前用户安装，提供可选桌面快捷方式，不添加开机自启。升级前退出面板，个人设置会保留；卸载默认保留设置，可明确选择删除，静默卸载始终保留。

免安装版完整解压后运行 `AirspyPanel.exe`，保留旁边的 `.config` 文件。两种版本均使用 `%LOCALAPPDATA%\AirspyPanel` 保存设置，升级不重置增益、端口或路径。旧中文设置继续使用中文，新用户跟随系统，不支持的语言回退英语。

## 首次使用

另行下载 [ADS-B SPY Windows 版](https://airspy.com/download/) 和 [VRS](https://www.virtualradarserver.co.uk/Download.aspx)。保留解码器原包 DLL。面板不内置第三方程序或驱动；VRS 可能另需启用 Windows 的 .NET Framework 3.5 功能。

设置首页点击“自动查找本机配置”，或在“程序与地图”选择 `airspy_adsb.exe` 和 `VirtualRadar.exe`。扫描常见目录，可取消，跳过无权限目录及目录链接，不遍历整块硬盘、不启动第三方程序、不修改 VRS。找不到时指定更小的文件夹。有效路径保留，多个候选需选择，检测后点击保存。

连接 Airspy R0、R2 或 Mini 与 1090 MHz 天线，关闭占用设备的其他软件。依次点击“开始接收”“配置并启动 VRS”“打开飞机地图”。配置时正常关闭已运行的本机 VRS，备份配置、更新并重启，不再重复确认。无法正常关闭时报告原因，不强制结束 VRS。

## 地图、状态和信号

默认地图为 `http://127.0.0.1/VirtualRadar/`，也接受 `/VirtualRadar/desktop.html#` 页面地址。修改过网页端口时需同步填写。面板自动生成 `AircraftList.json` 地址。解码器和 VRS 使用相同 TCP 数据端口（默认 30005）和 Beast 格式；网页端口与数据端口不是一回事。

灰色为未确认，绿色为接口、来源和配置匹配，黄色为接口正常但来源或配置待确认，红色为不可达。点击状态查看详情与检测时间。在线零飞机正常；地图底图失败不等于本机数据接口失败。多个匹配接收机可在设置中选择，支持自定义名称；本地配置不匹配不会阻止打开地图。

平均与峰值表来自最近 3 秒 Beast 报文的相对电平，0–255 换算到 0–100%，不是校准 dBm、频谱或噪声底。飞机计数按最近 60 秒 DF11/17 显式 ICAO 地址去重；VRS 的超时与统计方法可能不同。

## 操作与偏好

完整模式可缩放；简易模式约 320×620 DIP 固定尺寸，受屏幕工作区限制。设置、日志和详情在窗口内切页，切换模式不会重启接收。支持浅色、深色及跟随系统。设置首页切换六种语言，即时生效，不重置接收或输入；第三方原始输出及系统异常详情保留原文。

“全部停止”停止面板启动的解码器并正常关闭本机 VRS，包括手动启动的 VRS；浏览器地图标签保留。退出程序使用同样流程，VRS 退出失败时可重试、取消或明确选择只退出面板。收起托盘继续接收；首次关闭询问，可记住选择，并可在“外观与关闭行为”更改。双击托盘恢复原页面，再次启动唤回已有实例。

从“设置 → 运行日志”进入，默认看关键事件，警告与错误突出显示，重复事件合并，原始输出独立查看。向上滚动暂停跟随，“回到最新”恢复；导出遵循当前视图与筛选。两类视图各最多保留 500 条，普通接收日志不自动落盘。

高级设置：增益 auto 或 0–21，过高可能失真；12/20/24 MHz 是采样模式，不是 1090 MHz 接收频率，也不能提供单机 MLAT，24 MHz 需兼容的 R2；过滤范围 1–60、默认 4，高值可能增加 CPU 开销；USB 位打包 `-p` 是传输选项，不是 Bias-Tee 供电。恢复推荐值不覆盖路径及地图地址。

## 排查与维护

无报文时检查设备占用、天线、驱动、USB 和接收环境。VRS 离线时核对网页地址、端口与运行状态；详情区区分超时、错误网页、无效 JSON 和来源不符。返回 AdGuard 页面时检查本机网页过滤规则。不要只根据零飞机判断故障。

VRS 备份保存在 `%LOCALAPPDATA%\VirtualRadar` 配置旁，手动恢复前退出 VRS。反馈问题时提供版本、Windows 版本、语言及复现步骤，分享前移除私人路径、位置、接收数据和凭据。实际验证范围见仓库验证记录。

## 构建、原理与许可

源码目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1`，输出在 `bin`。使用 `bin\AirspyPanel.exe --self-test`、`--render` 和 `--render-languages` 分别进行业务自测、布局和国际化渲染。安装器依赖见 CONTRIBUTING.md。

数据链路：Airspy 硬件 → ADS-B SPY → Beast TCP → 面板与 VRS → 浏览器地图。面板负责控制进程和观察解码数据，不替代解码器或地图服务器。自制代码与文档采用 MIT，Airspy、VRS 及组件保留各自许可；不假定 ADS-B SPY 允许二次分发。
