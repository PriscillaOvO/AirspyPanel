# AirspyPanel 3.0 ユーザーガイド

[English](en-US.md) · [简体中文](zh-CN.md) · [日本語](ja-JP.md) · [Français](fr-FR.md) · [Deutsch](de-DE.md) · [Русский](ru-RU.md)

## インストールと更新

AirspyPanel は Airspy ADS-B 受信と Virtual Radar Server (VRS) を操作するコミュニティ製 Windows パネルです。Airspy や VRS の公式製品ではありません。Windows 10/11 と .NET Framework 4.8 が必要です。開発時の検証環境は Windows 11 x64 であり、自動テストは他の OS や実機受信の認証ではありません。

[Releases](https://github.com/PriscillaOvO/AirspyPanel/releases) からインストーラー EXE または ZIP を入手し、PowerShell の `Get-FileHash` で `SHA256SUMS.txt` と照合してください。配布物は未署名です。セキュリティソフトを無効にしないでください。インストールは現在のユーザーのみを対象とし、デスクトップショートカットは任意、自動起動は追加しません。更新前にパネルを終了してください。設定は更新後も保持され、アンインストール時も明示的に削除を選ばない限り保持されます。サイレント削除は設定を保持します。

ZIP は完全に展開し、隣の `.config` を残して `AirspyPanel.exe` を実行します。両方式とも `%LOCALAPPDATA%\AirspyPanel` に設定を保存します。既存のポート、利得、パスは維持されます。旧中国語設定は中国語のまま、新規設定はシステム言語に従い、未対応言語は英語になります。

## はじめに

[ADS-B SPY Windows 版](https://airspy.com/download/) と [VRS](https://www.virtualradarserver.co.uk/Download.aspx) を別途インストールし、デコーダー付属の DLL を残してください。第三者製プログラムやドライバーは同梱されません。VRS 自体に Windows の .NET Framework 3.5 機能が必要な場合があります。

設定でプログラムを自動検出するか、「プログラムと地図」で `airspy_adsb.exe` と `VirtualRadar.exe` を選びます。検索は一般的な場所のみで、キャンセル可能です。アクセス不能な場所とディレクトリリンクをスキップし、全ドライブ検索、プログラム起動、VRS 設定変更は行いません。見つからなければフォルダーを指定します。有効なパスは保持し、複数候補は手動選択します。結果は明示的に保存してください。

Airspy R0/R2/Mini と 1090 MHz アンテナを接続し、同じ機器を使うアプリを閉じます。「受信開始」「VRS を設定・起動」「航空機地図を開く」の順に操作します。実行中のローカル VRS は正常終了後に設定をバックアップ・更新し、再起動します。二重確認はしません。終了できなければ理由を表示し、強制終了はしません。

## 地図と信号

既定 URL は `http://127.0.0.1/VirtualRadar/`。`/VirtualRadar/desktop.html#` も使用でき、`AircraftList.json` を自動生成します。Web ポートを変えた場合は URL に反映します。デコーダーと VRS の TCP データポート（既定 30005）と Beast 形式を一致させてください。Web ポートは別です。

灰色は未確認、緑は API・ソース・設定一致、黄は API 正常だがソースまたは設定未確認、赤は接続不能です。状態をクリックして時刻と詳細を確認します。機数 0 でも正常です。地図タイル失敗とローカル API 失敗は別です。複数受信機は設定で選択でき、独自名称も使えます。設定不一致でも地図は開けます。

平均・ピーク値は直近 3 秒の Beast 相対レベルを 0–255 から 0–100% に変換したものです。校正済み dBm、スペクトル、ノイズではありません。機数は 60 秒以内の DF11/17 の明示 ICAO アドレスを重複排除して集計します。VRS と集計方法が異なる場合があります。

## 操作と設定

通常画面はサイズ変更可能、簡易画面は約 320×620 DIP 固定で画面作業領域に制限されます。設定、ログ、詳細は内部ページで開き、モード切替は受信を再起動しません。ライト、ダーク、システムテーマと六言語に対応します。言語は即時変更され、受信や入力をリセットしません。外部プログラム出力とシステム例外詳細は原文です。

「すべて停止」はパネルのデコーダーとローカル VRS（手動起動分を含む）を終了します。地図タブは残します。アプリ終了も同じ処理です。VRS 終了失敗時は再試行、キャンセル、または VRS を残してパネルのみ終了を選べます。トレイ格納は受信継続です。初回終了時の選択を記憶でき、外観と終了動作から変更できます。トレイをダブルクリックすると元ページに戻り、二度目の起動は既存画面を復元します。

設定の実行ログは主要イベントを表示し、警告とエラーを強調、重複を集約します。生の出力は別表示です。上にスクロールすると追従停止、最新へで再開します。エクスポートは現在の表示とフィルターに従います。各表示 500 件までメモリ保持し、通常の受信ログは自動保存しません。

詳細設定：利得 auto または 0–21、過大な利得は歪みの原因。12/20/24 MHz はサンプル設定であり受信周波数 1090 MHz ではなく、単独 MLAT はできません。24 MHz は対応 R2 専用。フィルターは 1–60、既定 4、高値は CPU 負荷増。USB `-p` は転送設定であり Bias-Tee 給電ではありません。推奨値復元はパスと URL を変更しません。

## トラブル対応・開発・ライセンス

受信しなければ機器占有、アンテナ、USB、ドライバー、環境を確認します。VRS 接続失敗は URL、Web ポート、サービスを確認し、詳細でタイムアウト、HTML/JSON、ソース不一致を区別します。AdGuard ページの場合はローカルフィルターを確認します。機数 0 だけで故障と判断しないでください。

VRS バックアップは `%LOCALAPPDATA%\VirtualRadar` の設定横にあります。手動復元前に VRS を終了します。問題報告にはバージョン、OS、言語、再現手順を記載し、パス、位置、受信記録、認証情報を削除してください。実際の検証範囲はリポジトリの検証記録を参照してください。

ソースで `powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1` を実行すると `bin` に生成します。`bin\AirspyPanel.exe --self-test`、`--render`、`--render-languages` で検証します。インストーラー構築は CONTRIBUTING.md を参照してください。

データ経路：Airspy → ADS-B SPY → Beast TCP → パネルと VRS → ブラウザー地図。パネルは制御と監視を担い、デコーダーや地図サーバーを置き換えません。自作コードと文書は MIT、第三者製品は各自のライセンスです。ADS-B SPY の再配布権は仮定しません。
